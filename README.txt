SIMULADOR DE MEMORIA EN PYTHON
==============================

Contenido:
- first_fit_arreglo.py
- first_fit_listas.py
- best_fit_arreglo.py
- best_fit_listas.py
- worst_fit_arreglo.py
- worst_fit_listas.py

Cada algoritmo tiene dos versiones:
1) Arreglo: cada posición representa 1 KB.
2) Listas: la memoria se representa por bloques [inicio, tamaño, estado, PID].

Los ejemplos están comentados y pensados para ser fáciles de explicar.
